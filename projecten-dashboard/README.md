# Projecten-dashboard

Eén overzicht van al je projecten. Het werkt offline, zonder installatie en zonder account.

## Openen op je computer
1. Download `index.html` (op GitHub: open het bestand → knop **Download raw file**).
2. Zet het bijvoorbeeld in `Documenten/Projecten/`.
3. Dubbelklik om het in je browser te openen. Zet er eventueel een bladwijzer of snelkoppeling op het bureaublad naar.

## Wat zit erin
- **Bord**: sleep projecten tussen Idee → Gepland → Bezig → Wacht → Klaar.
- **Lijst**: compacte tabel; klik op een kolomkop om te sorteren.
- **Per project**: status, prioriteit, categorie, deadline, *volgende stap*, takenlijst met voortgang, links en notities.
- **Snelfilters**: 🔥 Focus (hoge prio + bezig), ⏰ deadline binnen 7 dagen, 💤 stilgevallen (14+ dagen niet bijgewerkt).
- **Sneltoetsen**: `N` nieuw project · `/` zoeken · `Esc` sluiten.

## Opslag en back-up
Je gegevens worden alleen opgeslagen in de browser op je eigen computer.
Klik af en toe op **Back-up opslaan**: je krijgt dan een `.json`-bestand. Met **Back-up terugzetten** zet je dat terug, ook op een andere computer.
Let op: als je de browsergeschiedenis of sitegegevens wist, ben je je gegevens kwijt, tenzij je een back-up hebt.
